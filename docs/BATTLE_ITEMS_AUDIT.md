# 배틀 지닌도구 점검 — 2026-11-13

앞선 점검에서 발견한 도구 기능 차이를 구현했다. 원본 Mac의
`BattleItemPicker.swift`, `BattleItemLoadout.swift`, `BattleInspectionText.swift`와
비교하고, 격리된 저장 및 실제 숨김 Electron 창에서 검증했다.

## 확인한 동작

- UI/엔진/원본 Mac 자료가 동일한 도구 102종이다. 이름·설명은 모두 8개 언어로
  들어 있고, 실제 데이터는 8개 분류와 전체 탭으로 표시한다.
- 현재 지원 종에 호환되는 도구 102종의 엔진 초기화가 통과했다. 메가스톤 64종은
  실제 메가진화 명령을 실행해 성공했다. 맞지 않는 메가스톤·알 수 없는 도구·
  같은 팀의 중복 도구는 서버 측에서도 거부한다.
- 같은 시드에서 먹다남은음식의 회복과 신비의물방울의 위력 증가를 확인했다.
  자뭉열매 소모와 구애스카프의 기술 제한도 동작했다.
- 동일한 96개 시드의 기합구슬 비교에서 도구 없음은 32회, 광각렌즈는 23회
  빗나갔다. 특정 표본의 실행 결과이며 전체 명중 확률 추정값으로 사용하지 않는다.
- 도구를 눌러 미리보기만 하거나 취소하면 장착값과 기억값은 바뀌지 않는다.
  적용하면 개체별 기억값이 저장된다. 메가스톤의 종별 필터와 팝업 경계도 실제
  렌더러에서 확인했다.
- 구애스카프 장착 뒤 저장소를 다시 열어 도구·PP·기술 제한이 동일하게 복원됐다.
- 기존 챌린지의 7종 회복 상점은 지닌도구와 별도이며, 구매·보상·다음 대전의
  실제 IPC 흐름도 재실행해 통과했다.

## 차이점 반영 결과

| 구분 | 구현 결과 |
|---|---|
| 컬렉션 기본 도구 | 보유한 졸업 개체의 상세 화면에서 지정·해제. 재시작·Windows 백업·Mac v2 가져오기·교환 데이터에 보존 |
| 장착 우선순위 | 이번 선택 → 호환되는 컬렉션 기본 도구 → 최근 배틀 도구. 중복 시 등록 순서의 첫 개체만 장착하며 저장된 선호 값 보존 |
| 사용 중인 도구 | 행을 선택해 설명과 사용 중 안내를 확인하고 적용만 차단 |
| 동일 도구 | 현재 값과 같으면 적용 비활성화. 취소·미리보기는 저장하지 않음 |
| 번역·기술 제한 | 8개 언어의 없음·안내·장착 상태와 PP/구애 도구 등 제한 원인 표시 |
| 키보드 선택 | 위/아래 방향키·Home/End·PageUp/Down·이름 검색·Enter 적용·Escape 취소 |
| 팝업 영역 | 360/490px 홈 창과 660px 배틀 창에서 8개 언어 경계 검사 |

`tests/held-items.test.mjs`는 기본 도구 저장·재시작·교환·백업과 Mac v2 복원을
검사한다. 잘못된 도구·비호환 메가스톤·육성 중/놓아준 개체에 대한 변경은
기존 저장을 그대로 보존하며 거부한다. 컬렉션 기본 도구는 최근 배틀 장착값과
독립적으로 저장한다.

원본 모듈에 연결한 `scripts/build-mac-held-items-oracle.mjs`와
`POKE_MAC_HELD_ITEMS_ORACLE`로 15개 동일 입력의 장착 결과를 대조했고 일치했다.
실제 렌더러 검사는 `scripts/runtime-ui-smoke.mjs`와
`scripts/battle-ui-smoke.mjs`에서 공통 `scripts/held-items-ui-checks.mjs`를 실행한다.
컬렉션 버튼의 실제 IPC 저장, 배틀 후보의 기본 도구 전달·우선 적용도 검사한다.
전체 자동 테스트는 80개 통과·실패 0·건너뜀 0이다.

Windows 실기기에서의 입력·렌더링 검증은 별도로 남아 있다.
