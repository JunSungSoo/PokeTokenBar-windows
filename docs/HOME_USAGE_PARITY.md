# 홈·상세 사용량·회고 반영 — 2026-11-13

대상은 탭별 점검 보고서의 홈과 사용량/회고 화면이다. 사용자가 이번 범위를
`홈·상세 사용량·회고 먼저`로 선택했다. 후속 상점·가방·컬렉션·교환·배틀·설정
차이의 구현 완료를 뜻하지 않는다.

## 표시와 이동

- 오늘 합계는 크게, 정확한 토큰 수·비용은 보조 정보, 주/월 합계는 작은 인라인
  정보로 표시한다. Claude Code·Codex의 작은 제공자 버튼과 누적 막대 그래프를 유지한다.
- 선택 제공자에 입력·출력·캐시 쓰기·캐시 읽기, 복수 모델별 오늘 사용량을 표시한다.
  모델별 합계는 오늘 집계와 같은 중복 제거 입력에서 계산한다. 없는 모델을 추정하지 않는다.
- `상세`는 Mac의 주·월·연 회고로 이동한다. 이전/다음/현재 기간, 합계·이전 기간 대비,
  최고의 날·활동 일수·최장 연속·졸업 수와 최대 4개의 졸업 포켓몬을 표시한다.
- 회고는 달력 기간을 사용하고, 진행 중인 기간은 이전 기간의 같은 경과 일수와 비교한다.
  이전 기간의 기록 범위가 부족하면 증감률을 표시하지 않는다. 미래 기간은 탐색할 수 없다.
- 뒤로 버튼/Escape로 홈의 스크롤과 상세 버튼 포커스를 복원한다. 회고의 장치 모양과
  8칸 분할 게이지는 원본 `UsageRecapView.swift`의 구조를 따른다.
- 그래프 전환 버튼으로 최근 16주 히트맵을 본다. 그래프 모드·기간은 설정에 저장한다.
  기록 시작 전과 미래 칸은 알려진 사용량 0과 구분한다.
- 복수 공식 한도 계정 선택과 상대 리셋 시간을 표시한다. 한도 미지원 제공자는 해당
  영역을 숨긴다. 조회 실패에서는 설정의 로그인 정보를 다시 확인할 수 있다.
- 백그라운드 집계와 공식 한도 갱신 결과를 홈으로 전달한다. 회고를 보는 동안에도
  최신 사용량과 육성 기록을 사용한다.
- 길어진 홈 진화 라인에는 좌우 이동 버튼을 표시한다.

## 사용자 지정 유지

포켓몬 뒤 파트너 카드의 별도 배경·테두리·그림자를 제거해 창 배경을 그대로 쓴다.
경험치 바는 9.8px·테두리 없음이며, 현재 능력치 게이지의 색과 둥근 끝도 유지한다.
클릭 가능한 포켓몬의 호버 피드백, 기존 Windows 테마와 다른 탭의 디자인은 유지한다.
성장 바 수치는 기존 툴팁으로 확인하며 호버 시 두께를 바꾸지 않는다.

## 기록과 비교 근거

`usage-history-v1.json`은 사용량에서 파생한 날짜별 합계 캐시다. 월의 첫날부터 기록 범위를
알리고 날짜별 최댓값을 보존한다. 재시작·월 변경·로그 정리로 회고가 줄어드는 일을 막고,
현재 연도와 이전 연도를 보존한다. 육성·지갑·보상 집계의 입력으로 재사용하지 않는다.
Mac과 같이 첫 집계 전의 과거 월을 사용량 0으로 꾸미지 않는다. 따라서 과거 회고는
앱이 실제 기록한 범위부터 제공한다.

원본 `UsageRecap.swift`의 `UsageLedger`, `RecapPeriod`, `UsageRecap.make`와 비교했다.
원본 모듈에 연결한 `scripts/build-mac-usage-recap-oracle.mjs`로 주/월/연 × 두 날짜 ×
현재/이전 기간의 **12개 동일 입력 결과가 일치**했다. 수치뿐 아니라 기간 경계,
버킷의 기록 여부, 이전 합계, 증감률, 최고의 날, 연속 사용과 이전 탐색 가능 여부도 비교한다.

  회고 3종·탐색·Escape·포커스 복원, 히트맵 저장, 제공자 전체 비활성화와 긴 진화 라인 검사.
