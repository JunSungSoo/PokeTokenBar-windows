# Windows 버전 전환 — 2026-11-16

배포 버전: **1.0.1**. 새 ZIP을 별도 폴더에 모두 압축 해제하고 `PokeTokenBar.exe`를 실행하면, 동일 사용자 데이터 폴더를 사용하는 기존 하위 버전에서 새 버전으로 전환한다.

## 동작

- 실행 파일의 앱 이름, 진입점, 버전을 확인하고 실제 단일 인스턴스 소유 프로세스에만 종료를 요청한다. 같은 버전과 낮은 버전은 기존 상위 버전을 대체하지 않는다.
- 1.0.1 이후 버전끼리는 저장·설정 쓰기와 진행 중인 교환 커밋을 마친 뒤 종료한다. CPU 배틀은 재개 가능한 체크포인트를 유지한다. LAN 배틀 연결은 종료하고 기록을 저장한다.
- 협조 전환 기능이 없는 기존 1.0.0은 JSON 저장을 `upgrade-backups`에 백업한 뒤 Windows Restart Manager로 정상 종료를 요청한다. 강제 종료하지 않으며 종료에 실패하면 새 앱의 데이터 초기화를 진행하지 않는다. 기존 종료 처리에서 바뀌는 플로팅 펫 활성 설정은 종료 후 복구한다.
- 새 앱이 소유권을 얻은 뒤 사용자별 로그인 Run 등록, 기존 바탕화면·시작 메뉴·시작프로그램 폴더·고정된 작업 표시줄의 바로가기, `poketokenbar:` URL 연결을 새 실행 경로로 갱신한다. 기존 자동 실행 항목 이름·인수와 사용 안 함 상태를 보존한다. 자동 실행을 새로 켜지 않는다.
- 다른 앱이나 더 높은 버전을 가리키는 바로가기는 유지한다. 기존 실행 파일·폴더는 삭제하지 않는다.
- 최근 실행한 상위 버전 경로를 데이터 폴더에 기록한다. 이후 이전 협조 버전 실행 시 유효한 상위 버전을 열거나 실행 중인 상위 버전에 요청을 전달한다.
- Google Drive 다운로드 버튼은 계속 브라우저를 연다. 다운로드된 새 앱을 실행하는 시점에 전환한다.

## 검증

- `pnpm typecheck`, `pnpm build`, `git diff --check` 통과.
- `pnpm test`: 132개 중 122개 통과, 실패 0개. 기존 Swift/macOS 전용 10개 제외.
- 실제 패키징한 1.0.0 → 1.0.1 → 1.0.2 테스트용 실행 파일로 기존 프로세스 종료, 단일 소유권, 동일 저장 데이터, 펫 설정 보존 확인. 한글 경로, 로그인 시작 인수, 같은/낮은 버전 실행, 상위 버전 두 개 동시 실행, 상위 버전 실행 중 이전 협조 버전 재실행 포함.
- 격리된 HKCU 테스트 키와 실제 `.lnk`·URL 등록으로 시작프로그램 경로 변경, 비활성 승인 바이트 보존, 별칭·추가 인수·한글 경로 보존, 무관한 앱·상위 버전 바로가기 유지 확인.
- 실제 배틀 IPC에서 일반 종료 확인과 버전 전환 시 CPU 체크포인트 보존 확인. 설정·런타임 UI 검사 통과.
- 최종 포터블 ASAR 및 외부 PowerShell 스크립트 31개를 빌드 출력과 해시 비교.

실행 전환 테스트는 `PTB_STATE_DIR`로 분리한 프로필에서 수행했다. 사용자 실행 중인 앱과 실제 시작프로그램 항목은 테스트로 변경하지 않았다. 1.0.2는 전환 검증용으로만 생성하며 배포 ZIP은 1.0.1이다.
