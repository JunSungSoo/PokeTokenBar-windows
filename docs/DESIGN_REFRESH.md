# 크림·레드 UI 적용

일반 앱 화면은 `src/renderer/theme.css`에서 크림색 배경, 잉크색 본문, 레드 선택 상태, 주황색 성장 게이지, 초록색 공식 한도를 사용한다. 기존 시스템/라이트/다크 설정을 따른다.

- 홈·상점·가방·도감·교환·배틀 진입 화면과 설정·붉은 단풍 창에 공통 테마 적용.
- 상단 메뉴와 하단 도구를 고정하고 활성 콘텐츠 내부에서 스크롤. 기본 창은 490×740 이하로 작업 영역에 맞춘다. 360px 폭과 작은 높이도 지원한다.
- 도감은 4×4, 기존 필터·포획 기록·상세 기능을 유지한다. 카드에 최소 스프라이트 공간을 확보하고 육성 중 배지를 제목과 분리한다.
- 포켓몬 및 아이템 원본 이미지, 타입 색상, 애니메이션, 플로팅 펫, 실제 전투 창은 이 디자인 작업에서 교체하지 않는다. `battle.html`은 새 테마를 로드하지 않는다.
- 공식 한도 게이지는 조회 결과를 사용하며 사용량/남은 양 설정에 맞춰 전환한다. 초기화 시각 표시 중 브라우저 `window`를 가리던 루프 변수도 수정했다.

## 실제 화면 재생성

```sh
pnpm build
pnpm exec electron scripts/design-preview.mjs
```

`output/design-preview/app-redesign.png`는 실제 렌더러의 홈·도감·배틀 진입 화면을 나란히 캡처한 이미지다. 같은 폴더에 상점, 가방, 교환, 홈 하단, 작은 창, 다크 테마 캡처도 저장한다. 예시 사용량과 별도 임시 저장을 사용하며 사용자 세이브를 읽거나 변경하지 않는다. 원본 포켓몬 이미지를 불러오려면 네트워크가 필요하다. 캡처는 macOS Electron 개발 환경 결과이며 Windows OS 실기 검증과 구분한다.

## 검증

- `pnpm build`
- `pnpm test`
- `pnpm exec electron scripts/runtime-ui-smoke.mjs`: 8개 언어, 360/490/600px, 실제 구매·사용 IPC, 도감 상세, 기술 교체, 설정, 공식 한도 초기화 시각 및 사용량/남은 양 전환.
- `scripts/design-preview.mjs`: 밝은/어두운 테마 캡처, 360/490px 카드 경계 및 스프라이트 최소 표시 공간 확인.
