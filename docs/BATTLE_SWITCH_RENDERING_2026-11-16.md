# 배틀 교체 표시와 종별 크기 — 1.0.2

교체 이벤트의 새 장면을 안내 문구와 함께 먼저 그린 뒤 원본 출전 애니메이션을 준비하여, 새 포켓몬이 잠깐 노출되고 다시 들어오는 문제가 있었다. 연출 iframe도 준비 완료 전에 표시되어 로딩 중 비거나 이전 프레임이 나타날 수 있었다.

교체 안내·이미지 로딩 중에는 기존 장면을 유지한다. 두 원본 연출 레이어의 준비와 0ms 첫 프레임 렌더가 끝나면 표시를 전환한다. 종료 시에는 새 포켓몬의 정적 장면을 먼저 준비하고 레이어를 숨긴 뒤 원본 플레이어를 정리한다. 초기 트레이너 등장도 출전 완료 전까지 해당 진영을 숨긴다. 원본 Mac 플레이어 리소스는 수정하지 않았다.

기존 종별 높이는 `80 × √신장(m)`에서 96px 이후 약 112px로 강하게 압축됐다. 새 높이는 `72 × 신장(m)^0.65`를 사용하고 112px 이후 부드럽게 140px까지 제한한다. 151px 무대의 11px 지면 여백과 폭 제한은 유지한다. 동일 계산 결과를 정적 스프라이트와 원본 기술·교체 연출에 사용한다.

검증은 실제 배틀 IPC와 원본 애니메이션으로 수행한다. 출전 준비를 의도적으로 대기시켜 기존 포켓몬이 유지되는지 확인하고, 종료 직전에는 새 포켓몬이 준비된 상태에서 연출이 숨겨지는지 확인한다. 실제 앞/뒤 이미지로 파쪼옥·피카츄·거북왕·망나뇽·강철톤·고래왕을 비교한다. 모든 1~649번 종의 양쪽 방향 계산이 유효한 범위에 있는지도 검사한다.

전체 테스트 134개 중 124개 통과, 기존 Mac/Swift 전용 10개 제외. 타입 검사와 빌드 통과. 비교 이미지와 화면 캡처는 `output/battle-switch-fix`에 저장한다.
