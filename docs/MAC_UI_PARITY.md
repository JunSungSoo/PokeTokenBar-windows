## 유지하는 사용자 지정

- 홈 포켓몬 뒤 별도 배경 없음. 클릭 가능한 곳에만 호버 피드백.
- 홈 경험치 두께 9.8px, 테두리 없음. 상세 현재 능력치는 같은 주황색과 둥근 양끝.
- 상세의 기본 능력치 표·종족값 합계는 표시하지 않음.
- 가방의 실행 버튼과 붉은 단풍 선택 창은 `사용`으로 통일. 보유형 부적은 자동 적용 표시 유지.
- 드롭다운 화살표·문구·이미지는 소속 영역 안에 유지. 긴 번역은 줄바꿈/생략.

알 3종은 원본 `ShopView.swift`의 `EggCard`와 동일한 `egg.png`를 공유한다. 원본은 별도 등급별 알 이미지 없이 고급(초록)/희귀(파랑) 배지를 이름 바로 옆에 표시해 구분한다.

## 검증

- `pnpm test`: 상점/가방 순서, 원본 PNG 해시, 원본 ItemKind·타입 색상, 기분 판정, 진화 분기 숨김 및 기존 집계·저장·교환 회귀 검사.
- `pnpm exec electron scripts/runtime-ui-smoke.mjs`: 8개 언어, 360/490px 및 설정 창의 긴 번역, 실제 구매·사용, 부적 재구매 방지·이동, 사탕/민트 홈 복귀, 붉은 단풍 창·재고 감소, 4×4 카드 경계, 지연 응답·재시도.
- `POKE_UI_REAL_SPRITES=1 POKE_UI_SCREENSHOTS=<경로>`를 지정하면 실제 원본 포켓몬 이미지로 홈/상점/가방/컬렉션/로그/단풍 선택 창을 캡처한다. 테스트 저장은 임시 폴더에만 기록한다.
- Swift 원본 비교 도구를 지정하면 기존 사용량·교환·프레임 타이밍·상세 능력치 비교도 함께 실행한다.

플랫폼 기본 폰트·텍스트 안티앨리어싱·창 테두리·이모지 폴백은 OS에 따라 달라진다. 화면의 데이터 순서·원본 PNG·영역·컨트롤 계층·행동을 비교하며, OS 렌더링까지 픽셀 단위로 같다고 주장하지 않는다.
